# Writeups

Personal walkthroughs for machines I've rooted — mostly HackTheBox, occasionally other platforms. Written as narrative, first-person notes: what I tried, what failed, why it failed, and how I actually got in. Rabbit holes are documented, not edited out.

Each box gets its own .md file, named after the box. Browse the repo file list for the full set.

Format

Each writeup generally follows the same structure:

Summary — the full chain spoiled up front
Recon — what I found and how
Initial Access — the foothold
Lateral Movement / Privilege Escalation — getting from a limited shell to the flag
Root Cause Summary — one-line root cause per stage, for quick reference

Flags and attacker/target IPs are redacted or placeholdered (<flag>, <target-ip>, <kali-ip>); any real passwords/secrets shown are CTF credentials, not production ones.
